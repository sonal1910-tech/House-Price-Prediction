# 🏠 House Price Prediction

This project predicts the price of a house based on features such as area, number of bedrooms, bathrooms, and floors using a Machine Learning Linear Regression model in Python.

## 📌 Project Overview
The goal of this project is to estimate house prices from input features.  
A dataset in CSV format is used to train a regression model that learns the relationship between house characteristics and price.  
The trained model predicts the price of a new house.

## 🧠 Technologies Used
- Python
- pandas
- scikit-learn

## 📊 Input Features
- Area (sq ft)
- Bedrooms
